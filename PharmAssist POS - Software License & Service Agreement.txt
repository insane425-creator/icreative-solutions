## 4. DATA & BACKUP RESPONSIBILITY

### 4.1 Data Storage Architecture
- Data stored locally on each device via PouchDB
- All devices sync to Store Manager device (CouchDB server)
- Each device maintains backup of synced data
- Manual backup button available (saves database to local drive)
- Future: Automatic Google Drive backup (see Section 2.3)

### 4.2 Client's Responsibilities
**Client must ensure:**
- CouchDB password kept secure and confidential
- Windows C: drive database folders are protected from manual deletion
- Regular manual backups taken using backup button
- At least one device (preferably Store Manager) remains operational
- Devices not formatted/reinstalled without proper backup procedures

### 4.3 Data Liability
The Developer provides the tool to manage data, but the safety of the hardware and data integrity is the Client's responsibility. The Developer is NOT liable for data loss caused by:
- Hardware failure (Hard drive crash)
- Windows corruption or Virus/Ransomware attacks
- Theft of the computer
- Remote Wipe execution requested by the Client (e.g., in case of theft)
- Manual deletion of database folders from C: drive
- Computer formatting without proper backup
- Client's failure to maintain regular backups
- Unauthorized access due to weak or shared passwords
- Natural disasters, power surges, fire, flood, etc.

### 4.4 Developer's Responsibilities
**iCreative will:**
- Assist with data recovery attempts in case of corruption
- Provide clear guidance on backup procedures during training
- Help restore data from available backups when possible

**Important:** iCreative does NOT store client's transactional data (sales, purchases, invoices) on external servers. All data remains on client's premises under client's control.
